# btcthirst.github.io

Personal portfolio of Maksym Slobodianyk, Frontend & Web3 Engineer: https://btcthirst.github.io

A single static page (`index.html`) with inline CSS. No build step and no dependencies.

## Run locally

## Deploy

Served by GitHub Pages from the `main` branch. Push a change and the site updates in a minute or two.
